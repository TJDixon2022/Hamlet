# Seed instruction - the seed fixture

Shipped by hand into the fixture root. With `--seed`, iteration 1 must execute this file
as written and the arbiter must not be called. Without it, the arbiter is called first.

```
ARBITER-DECISION
STEP: 1
APPROACH: the seed instruction as shipped - run by iteration 1 with no arbiter authoring it
MOVE: continue
WHY: fixture - it proves which instruction iteration 1 ran
STATE: not started
DECIDED: none
LICENCE: none
ACCOMPLISHED: the shipped instruction ran
ADVANCES: step 1 - the fixture's one criterion, that iteration 1 ran the shipped instruction
END-ARBITER-DECISION
```
