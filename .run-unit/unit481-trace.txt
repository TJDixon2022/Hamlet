== WHERE THEY DIFFER, AND WHAT EACH CHANGES ON SCREEN
  1. Band lookup. TuneTo: HfBands.BandFor (10305). ApplyRigFrequency: BandFor ?? AmateurSpectrum.Nearest (22180).
     On screen: nothing inside a ham band. Off every ham band the announced path shows the nearest band; the chosen path cannot get there (it is clamped, 2).
  2. The clamp. OnFrequencyHzChanged clamps the chosen frequency to the map (13910) and not the announced one (HM-DEC-055).
     On screen: nothing inside the map; past the map's edge the announced dial is shown where the radio is.
  3. The rig write. Only the chosen path queues a write (14000).
     On screen: nothing. It is the radio being told, not the window.
  4. The mode. Only ApplyRigState sets RigModeText (11090) - on both paths, because the chosen path's mode is the radio's read-back of Hamlet's write.
     On screen: the same mode chip either way once the read-back arrives.
  5. The stand-down. NoticeOperatorModeChange (11209) fires only when the radio's mode changes and Hamlet did not write it: the announced path with a radio that had already reported a mode.
     On screen: ModeFollowSuspended true; the status line narrates behind the mark (StatusBarText, MainWindow.axaml 7001, 230.0 wide -> 0.0 in the headless fixture, which is not connected); the banner "You are setting the mode, so Hamlet is not" in the Dial tape panel (MainWindow.axaml 1181), which is not on screen on the CW tab at 1100 x 780 or 1920 x 1040. No panel moves.
     HM-DEC-056's rule, standing, and deliberate. Not changed by this unit.
  6. The privilege card and its colour. Both paths: UpdatePrivileges (22234) with LicenceModeForTheTab (526) - the tab, not the radio's mode. Neither path changes the tab.
     On screen: the same. On the CW tab at 14.0754 both windows say "Your General license covers Morse here" and "Your General license covers Morse here · 97.305(a)" - plan section 7's stale sentence is the tab rule of unit 251, the same on both paths, not a divergence of the two.
  7. Panel visibility and column spans (BandGovernsTheMapPanel, the card, the map, the rig face): read from the view off the same view-model properties. No path-specific input.
  8. The neighborhood panel's sentences (GreenZone, 1382): PrivilegeStatus, FrequencyHz, the neighborhood, ChosenDigitalMode - the same on both paths.
  9. The mode chips (DigitalModeChips) from FrequencyHz and ChosenDigitalMode - the same on both paths.
