===================

Unit 307 was to create this file and never ran; unit 309 created it from the
fallback list in its own instruction, section 1f. Unit 310 added its own five,
plus VoiceTests, which sweeps every string the operator can read and which any
unit adding copy should run. Unit 312, the first of the PSK31 phase, added its
own two, and unit 313 added its two plus TheConnectionLineReadsTests, which its
own instruction named and which was not on here. Unit 314 added its four. Unit 315
added its two, one each side. Unit 316 added its three, two engine and one app.
Unit 318 added its engine types as each went green. Unit 319 added its own the same
way. Unit 320 added its one app class, for item 41.

WHAT THIS IS. The test names a unit runs, filtered by exact name and
foregrounded, BEFORE it changes anything - so that a red found afterwards can be
told from a red that was already there. HM-DEC-155 forbids running a suite, and
this list is what a unit runs instead.

WHAT IS NEVER ON IT. A known red. The point of the list is that everything on it
should be green before a unit starts; a name that is expected to fail teaches the
next session to ignore a failure.

HOW TO RUN ONE
    timeout 480 dotnet test <project> --filter "FullyQualifiedName~TypeName"
