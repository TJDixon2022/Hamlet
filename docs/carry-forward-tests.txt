WHAT THIS IS. The test names a unit runs, filtered and foregrounded, BEFORE it
changes anything - so that a red found afterwards can be told from a red that
was already there. HM-DEC-155 forbids running a suite, and this list is what a
unit runs instead.

WHAT IS NEVER ON IT. A known red. The point of the list is that everything on it
should be green before a unit starts; a name that is expected to fail teaches the
next session to ignore a failure.
