===================

Unit 320 wrote this file (work instruction 320 task 1c, item 40). The list lived only
in work instruction 318 section 2, which is in git history and nowhere a unit can run it

WHAT THIS IS. Every test class that names Ft8TransmitSequence, Ft8ArmedSend or
OperatorSend - the classes that guard the transmit chain. A unit that goes near the send
path runs these, filtered by exact name and foregrounded, before and after, and compares
the reds by name.

WHAT IS DIFFERENT FROM docs/carry-forward-tests.txt. Known reds ARE on this list. It is
the list of what guards the chain, not a list that should be green; the reds on it are
named in each unit's report and are carried as ask 35. A red here is compared by name
against the unit before, never chased.

HOW TO RUN ONE
    timeout 480 dotnet test <project> --filter "FullyQualifiedName~TypeName"
