Carry-forward tests that were dropped
=====================================

WHAT THIS FILE IS FOR. `docs/carry-forward-tests.txt` is the list a unit runs
before it changes anything. It only ever grew: unit 309 created it with
fourteen names and by unit 323 it held forty-six, run as forty-one separate
`dotnet test` invocations, and that run is what the watchdog killed unit 323
over. Work instruction 324 task 1b cut it back.

**NOTHING HERE IS DELETED, RETIRED OR KNOWN RED.** Every name below is a test
that was green when it came off the list. It is simply not re-run at the start
of every unit. A unit that touches the subject matter beside a name here runs
that name itself, and may put it back.

**A KNOWN RED IS NEVER ON EITHER LIST.** The known reds stay where they have
always been, at the foot of `carry-forward-tests.txt`.
